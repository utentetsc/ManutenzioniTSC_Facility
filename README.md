# The Space Maintenance Manager

Sistema centralizzato per la gestione delle manutenzioni della rete The Space.

## Funzioni

- Login per ruolo
- Gestione Cinema
- Gestione Manutenzioni
- Gestione Criticità
- Upload PDF
- Import Excel
- Dashboard KPI
- Scadenziario Automatico

## Ruoli

ADMIN
REPORT
CINEMA

## Stack

Frontend:
Next.js + React + Tailwind

Backend:
ASP.NET Core 8

Database:
SQL Server

Storage:
Azure Blob Storage
